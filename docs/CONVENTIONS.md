# Conventions

## Language

Public repository: the prose is in English, so anyone can find and read it.

| Level | Language |
|---|---|
| Identifiers, file names, branches | English |
| Code comments, docstrings | English |
| `README.md` | English, canonical |
| `README.it.md` | Italian, translation of `README.md`, updated in the same commit |
| `docs/*`, `CLAUDE.md` | English |
| Commit messages | English, Conventional Commits, imperative mood |
| Dashboard UI, CLI output | English |
| GitHub description and topics | English |

`make lint` runs `scripts/check-prose.py`, which fails on Italian prose outside the paths allowed by default (the Italian README) and in `.prose-allow`.

## Glossary

The English terms used across docs, comments and UI. Translations of the Italian notes in the history use these.

| Term | Meaning |
|---|---|
| profile | A named entry in `config/llm-dash.toml` (`[profiles.<name>]`): model path, context, tier, chat template args. What `llm-up` and the dashboard start. |
| default profile | `server.default_profile`: the profile `llm-up`, `llm-serve` and `make up` start when no profile is given. |
| tier | `default` (agentic daily driver) or `other` (startable, but with a caveat). Rules in `docs/MODEL_SYNC.md`. |
| daily driver | A model good enough for everyday agentic coding on this hardware. |
| unified memory | The shared CPU/GPU RAM of Apple Silicon. |
| wired memory | Memory the GPU keeps resident, capped by `iogpu.wired_limit_mb`. |
| memory pressure | The macOS pressure level (low, medium, high) shown by the dashboard, derived from available memory and swap. |
| headroom | Free memory left after the model and its KV cache are loaded. |
| reasoning | The model's thinking tokens (`delta.reasoning` from `mlx_lm.server`), shown apart from the answer. |
| code fence | A fenced code block in Markdown (```` ``` ````). |
| stick to bottom | The chat following new text while the user stays near the bottom of the conversation. |

## Code

- **One model at a time**, every profile on port 1234. On 32 GB two MoE models of 16+ GB do not fit, and trying sends the system into swap.
- **No JS bundler**: Alpine, marked and highlight.js are static assets served from `/static`. Edit and reload the browser.
- **Tailwind v4, CSS-first**: the theme lives in `@theme` inside `src/input.css`; there is no `tailwind.config.ts`. `static/output.css` is generated by `pnpm run build` and never edited by hand.
- **`config/llm-dash.toml` is the single source of truth** for profiles and server settings. `bin/llm-serve`, `bin/llm-up` (through `bin/_config.py`) and `main.py` read it at runtime; nothing else hardcodes a profile.
- **Scripts in `bin/` are symlinked** into `~/.local/bin`, not copied: `./install.sh` backs up and recreates the links.
- **Comments say why**, not what: constraints, gotchas, non-obvious invariants. Every Python module and every public function has a docstring.
